## 📖 Overview

DaBubble is a modern real-time team communication platform inspired by Slack and Discord. The application enables users to collaborate efficiently through public channels, private conversations and threaded discussions.

Built with **Angular 20** and **Supabase**, the project focuses on scalability, clean architecture, responsive design and an intuitive user experience. Authentication, real-time messaging, database management and file storage are powered by Supabase.

---

## ✨ Features

- 🔐 Secure Authentication
- 👤 User Profiles & Avatar Management
- 💬 Public Channels
- 📩 Direct Messages
- 🧵 Thread Conversations
- 😀 Emoji Picker & Emoji Reactions
- 🔍 Search Messages, Users & Channels
- 🏷️ @User & #Channel Mentions
- ⚡ Real-Time Synchronization
- 📱 Fully Responsive Design
